# Vinyl and Film Solutions Demo Site

Vite + React demo website for Vinyl and Film Solutions.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to GitHub.
2. In Vercel, import the GitHub repo.
3. Framework should auto-detect as Vite.
4. Click Deploy.

## Images

Add images to:

```txt
public/images/primitive-werkz/
```

Use the names listed in `public/images/primitive-werkz/README.txt`.
